Lagrange-Gleichungen 2. Art für elektromechanische Systeme · Verschiebungs-Ladungs-Formulierung · Beispiel 7‑12, J. H. Williams, Fundamentals of Applied Dynamics
Kondensatormikrofon — nachgezeichnet nach Williams, Fundamentals of Applied Dynamics, Bild 7‑26 (Beispiel 7‑12).

Das System

Eine bewegliche Platte (die Membran) bildet zusammen mit einer festen, perforierten Rückplatte einen Kondensator. Trifft Schall auf die Membran, ändert sich der Plattenabstand — und damit die Kapazität. Die Batterie hält den Kondensator vorgespannt; der daraus entstehende Strom durch den Verstärkerwiderstand ist das Mikrofonsignal.

Von der Lagrangefunktion zu den Bewegungsgleichungen

dieselben vier Schritte wie an der Tafel

① Koordinaten

ξ = x  (Membranlage)
q  (Ladung),   i = q̇
x und q sind vollständig und unabhängig wählbar → das System ist holonom. Zwei Koordinaten ⇒ zwei Gleichungen.

② Lagrangefunktion

ℒ = T* − V + W*m − We
ℒ = ½mẋ² − ½kx² + 0 − q²2C(x)
ℒ = ½mẋ² − ½kx² + 0 − q²2C0
W*m = 0 — keine Spule im System. We ist direkt eine Funktion von q: keine Koenergie nötig.
C(x) = C0d0/(d0+x)
W*m = 0 — keine Spule im System. We ist direkt eine Funktion von q: keine Koenergie nötig.
ℒ enthält kein Produkt aus x und q — die beiden Koordinaten stehen nur noch nebeneinander.

③ Virtuelle Arbeit

δ𝒲nc = Ξ δx + ℰ δq
Ξ = F(t) − cẋ
ℰ = E0 − Rq̇
Dämpfer und Widerstand kommen über die virtuelle Arbeit herein — keine Rayleigh-Funktion.

④ Lagrange-Gleichungen

ddt ∂ℒ∂ẋ − ∂ℒ∂x = Ξ
ddt ∂ℒ∂q̇ − ∂ℒ∂q = ℰ
Elektrisch: ∂ℒ/∂q̇ = 0 ⇒ kein Produktregel-Term. Mechanisch: ∂ℒ/∂x liefert die elektrostatische Kraft.
Elektrisch: ∂ℒ/∂q̇ = 0 ⇒ kein Produktregel-Term. Mechanisch: ∂ℒ/∂x = −kx — ohne q, denn ∂We/∂x = 0. Die elektrostatische Kraft entfällt.
Mechanische Gleichung
Mechanische Gleichung · entkoppelt
mẍ + cẋ + kx + q²2C0d0 = F(t)
mẍ + cẋ + kx = F(t)
Der Term q²/(2C0d0) entfällt — ein gewöhnlicher gedämpfter Schwinger, ganz ohne Elektrik.
Elektrische Gleichung
Elektrische Gleichung · entkoppelt
Rq̇ + q(d0+x)C0d0 = E0
Rq̇ + qC0 = E0
x kommt nicht mehr vor — ein reiner RC-Kreis. Mit q(0) = E0C0 ist er bereits im Endzustand: q̇ ≡ 0.
Grenzfall dC/dx = 0. Die Platten stehen fest, C = C0 = const. Dieselben vier Schritte — nur hängt We jetzt nicht mehr von x ab. Die Gleichungen oben sind entsprechend hergeleitet.
Beide Domänen sind entkoppelt. Mit C = const verschwindet dC/dx — und damit der einzige Term, der die beiden Gleichungen verbunden hat. Links steht ein gedämpfter Schwinger, rechts ein RC-Kreis; keine der beiden Gleichungen weiß noch von der anderen. Die Membran schwingt weiter, die Ladung bleibt auf q0 = E0C0 stehen: kein Signal. Die Wandlung steckt also nicht in der Kapazität selbst, sondern allein in ihrer Ortsabhängigkeit.
Zwei Beobachtungen. In der elektrischen Gleichung koppelt x rein algebraisch — es gibt keinen ẋ-Term, also keine Bewegungsinduktion, wie sie ein induktiver Wandler hätte. Und für diese spezielle Kapazitätsfunktion kürzt sich die x-Abhängigkeit der elektrostatischen Kraft exakt heraus: übrig bleibt der konstante Term q²/(2C0d0). Genau diese beiden Gleichungen werden unten numerisch integriert (RK4).
